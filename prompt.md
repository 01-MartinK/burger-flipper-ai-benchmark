The current game is a burger flipping idea. Improve the game and implement the following new features.
1. Implement a new view("Counter") where the user sees the customers and when clicking on a customer a new order is placed.
2. Implement a new view("Storage") where the user has storage shelves with ingredients. The user selects ingredients it wants to use and they get added to trays.
3. Implement a new view("Prep table") where the user has to drag and drop ingredients onto a plate to assemble a burger. The view contains a table a plate and trays at the top where the ingredients lie.

The user has the selection of the following ingredients:
patty, lettuce, tomato, bun, onions, cheese and bacon.
Patties and bacon can be cooked in the "Grilling" view.

The mvp should resemble the game "papa's burgeria". Use the official wiki for ideas and mechanics.
